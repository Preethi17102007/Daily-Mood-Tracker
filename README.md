# Moodly — Daily Mood Tracker

A soft lavender daily mood tracker with a welcome screen, animated decorations, profile menu, calendar, analytics, history, journal, and dark mode.

## Run locally
1. Extract this ZIP.
2. Open the [1mindex.html[0m file in a modern browser.
3. Internet is needed for Google Fonts and Chart.js analytics.

## Data and privacy
Mood entries and profile preferences are stored in your browser's localStorage. This demo does not include a secure account system or cloud database.
